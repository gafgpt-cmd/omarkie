# The Shape of Words

## Small poems about writing, set in type

![Overlapping blots of blue, red, yellow and teal ink on paper](images/ink-bloom.jpg)

### I. Blank page

A blank page is not empty.
It is **waiting**.
It holds its breath
like a room before the music starts.

### II. Emphasis

Some words *lean in* and whisper.
Some words **stand up** and speak.
Some words ***do both at once***,
and some we ~~wish we hadn't said~~ keep for later.

### III. The highlighter

I read the book with a yellow pen,
and every line I loved
==turned into sunlight==.

## A note on typography

Type is the voice of a page. A heading says *listen*. A quote says *someone else said this, and it mattered*.

> Write it down.
> Then write it **better**.
> Then let it go.
>
> *Advice from a writing class, long ago*

> [!TIP]
> **Give the page a new voice.** Open **Preferences** (**Ctrl+,** or **⌘,**) and try a theme such as Toypora, Toyzetlr or Warm Paper, then pick fonts for text, headings and code. **Display → Toggle Light/Dark Theme** switches to night colours.

## The parts of a page

| Element | Markdown | What it says |
| :------ | :------- | :----------- |
| Heading | `# Title` | Start here |
| Bold | `**word**` | This matters |
| Italic | `*word*` | Say it softly |
| Highlight | `==word==` | Remember this |
| Strike | `~~word~~` | Changed my mind |
| Footnote | `[^1]` | There is more[^more] |

## Little marks, big jobs

The 1^st^ draft is for you. The 2^nd^ is for the reader.
A footnote waits at the bottom like a friend at the door.
Chemists write CO~2~. Poets write *breath*.

Type `:` and a few letters, like `:sun`, and Omarkie suggests an emoji. :sunny:

## Haiku in three fonts of mood

> **morning ink drying**
> *the word I almost deleted*
> `still there, still mine`

### IV. Save

Every poem here is a plain text file.
No account, no cloud, no lock.
Open it in ten years
and it will still say **hello**. :wave:
